# SuperSaga 🔥

A Marvel-themed React JS project showcasing 8 iconic superheroes with interactive cards, skill bars, animations, and detailed character pages.

## 🔥 Features
- Smooth hero section with scroll
- Responsive grid of hero cards
- Detailed character view with:
  - Origin, powers, and weapons
  - Animated GIFs
  - Glowing skill bars
- Fully built using React JS and CSS only (no APIs/backend)

## 🚀 Tech Stack
- React JS
- CSS (custom and responsive)
- Git & GitHub for version control
